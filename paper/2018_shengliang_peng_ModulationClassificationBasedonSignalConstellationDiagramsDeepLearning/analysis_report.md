# 论文拆解报告：Modulation Classification Based on Signal Constellation Diagrams and Deep Learning

-   **作者：** Shengliang Peng、Hanyu Jiang、Huaxia Wang、Hathal
    Alwageed、Yu Zhou、Marjan Mazrouei Sebdani 和 Yu-Dong Yao
-   **发表年份与期刊：** 2019，*IEEE Transactions on Neural Networks and
    Learning Systems*，第 30 卷第 3 期，第 718--727 页，2019 年 3 月
-   **DOI：** 10.1109/TNNLS.2018.2850703
-   **开源/常用数据集：** 论文没有使用或指出
    RadioML2016.10a、RadioML2018.01a 等公开 AMC
    数据集。实验将复基带采样数据转换为星座图像。论文提到样本可以来自实际接收机或计算机仿真，但没有给出公开数据集的名称或可下载的数据集。

## 1. 问题转化（Problem Formulation）

-   **研究问题：**
    本文研究使用卷积神经网络（CNN）进行自动调制识别（AMC）。核心问题是：如何将复数形式的接收信号样本转换为具有网格结构的图像数据，从而将成熟的图像分类
    CNN 应用于调制识别。
-   **机器学习问题形式：**
    有监督的八分类任务。给定一段接收复基带采样数据，模型判断生成该信号的调制方式属于八种候选类别中的哪一种。
-   **调制类别：** BPSK、4ASK、QPSK、OQPSK、8PSK、16QAM、32QAM 和
    64QAM。
-   **系统假设：**
    论文考虑相干、同步接收以及单音信号。假设载波恢复、定时恢复和波形恢复已经完成。最终输入为受到加性高斯白噪声（AWGN）影响的复基带序列。
-   **主要技术路线：** 先将复数采样点转换为基于星座图的图像，再使用
    AlexNet 或 GoogLeNet
    学习图像特征并完成调制分类。需要注意，这不是直接将原始 I/Q
    时间序列输入 CNN；在进入网络之前，信号已经被转换成图像表示。

## 2. 输入与输出（Inputs & Outputs）

### 输入（Input）

-   **原始信号：** 一段复基带采样序列，每个复数采样点都包含同相分量 I
    和正交分量 Q。
-   **每个分类样本的采样数量：** 使用 1,000
    个复数采样点生成一张星座图像。
-   **图像表示方式：** 论文研究了四种表示方式：
    1.  **星座图（Constellation Diagram）：**
        将采样点映射到二维复平面。如果一个或多个采样点落入某个像素区域，就将该像素标记出来。
    2.  **灰度图（Gray Image）：**
        使用落入每个像素区域的采样点数量作为像素强度，而不是简单地将所有被占用的像素设置为相同强度。
    3.  **增强灰度图（Enhanced Gray Image）：**
        除采样点数量外，还考虑采样点与像素中心之间的距离。每个采样点按照指数衰减权重对像素作出贡献，计算形式为
        `B(i,j) = P * exp(-lambda * d(i,j))`。其中，`P`
        表示采样点功率，`d(i,j)` 表示采样点 `i` 到像素中心 `j`
        的距离，`lambda` 控制衰减程度。
    4.  **三通道图像（Three-channel Image）：**
        使用三个不同的指数衰减参数，对同一组采样点分别生成三张增强灰度图，再将它们组合成三个图像通道。这三个通道是图像处理通道，并不代表三根天线或三路独立接收信号。
-   **复平面选取范围：** 除非另有说明，论文使用复平面上的 7 × 7
    区域。该范围是根据典型的 0～10 dB 信噪比范围确定的。
-   **CNN 输入尺寸：** AlexNet 使用 227 × 227 的图像，GoogLeNet 使用 224
    × 224 的图像。主要 CNN 分类实验采用三通道图像作为输入。

### 输出（Output）

-   **输出形式：** 一个八维概率向量，每个维度对应一种候选调制类别。
-   **最终判决：**
    根据网络输出的类别概率，选择对应的调制类别作为识别结果。
-   **任务范围：**
    输出是调制类别。论文不负责估计发送比特、恢复通信消息，也没有联合估计信道参数。

## 3. 数据集与实验设置（Datasets & Experimental Setup）

### 数据与样本构建

-   论文没有指出具体的公开数据集，也没有提供类似 RadioML
    的公开基准数据集划分。
-   根据论文描述的实现流程，每 1,000
    个复基带采样点生成一个带标签的图像样本。
-   对每一种调制类别，作者收集：
    -   100,000 张带标签图像用于训练；
    -   1,000 张带标签图像用于验证。
-   相关实验还报告了每种调制类别 1,000 次测试。SNR
    对比实验中，每个测试样本使用 1,000 个复数采样点。
-   论文对样本来源的描述较为笼统，指出数据可以来自实际接收机或计算机仿真，但没有提供可下载的数据集名称或完整的公开数据生成规范。

### 信号条件与调制类别

-   评估八种调制类别：BPSK、4ASK、QPSK、OQPSK、8PSK、16QAM、32QAM 和
    64QAM。
-   假设接收信号为相干、同步的复基带信号，并受到 AWGN 影响。
-   论文研究了包括 0 dB、4 dB 和 10 dB 在内的 SNR
    条件；平均准确率曲线覆盖 0～10 dB 范围。
-   在图像表示方式对比实验中，作者使用 SNR = 2 dB 的 8PSK 信号，并测试
    1,000 个样本。
-   在混淆矩阵实验中，作者使用三通道图像和 GoogLeNet，SNR 设置为 4
    dB，每种调制类别测试 1,000 个样本。

### CNN 模型与配置

-   **AlexNet：** 作者修改了 Caffe 提供的参考 CaffeNet。将最终输出维度从
    1,000 类改为 8 类，并将倒数第二个全连接层的神经元数量从 4,096 减少到
    512。学习率从 0.01 调整为 0.001，gamma 参数从 0.1 调整为 0.5，step
    size 从 100,000 调整为 10,000。Batch Size 为 64。
-   **GoogLeNet：** 将主分类器和两个辅助分类器的输出维度从 1,000 类改为
    8 类。学习率从 0.01 调整为 0.001，gamma 从 0.96 调整为 0.8。
-   **训练框架与硬件：** 使用 Caffe 进行训练。训练服务器配备 NVIDIA
    Tesla K40m GPU。论文报告 AlexNet 的训练时间约为 12.5 小时，GoogLeNet
    约为 24.3 小时，最大训练迭代次数为 200,000 次。
-   **图像分辨率与裁剪：** AlexNet 要求输入图像至少为 227 ×
    227，GoogLeNet 使用 224 ×
    224。提高图像分辨率并不一定能提升准确率。在论文报告的实验中，AlexNet
    使用 227 × 227 且不进行裁剪时效果较好。

### 对比算法（Baseline Algorithms）

论文比较了五种方法：

1.  **Cumulant：** 使用四阶累积量 `C40` 的传统信号处理分类方法。
2.  **SVM-7：** 使用七个累积量特征的
    SVM，包括三个四阶特征（`C40`、`C41`、`C42`）和四个六阶特征（`C60`、`C61`、`C62`、`C63`）。
3.  **SVM-5：** 使用五个特征的
    SVM，包括两个二阶特征（`C20`、`C21`）和三个四阶特征（`C40`、`C41`、`C42`）。
4.  **AlexNet：** 使用 AlexNet 进行 CNN 调制分类。
5.  **GoogLeNet：** 使用 GoogLeNet 进行 CNN 调制分类。

## 4. 评价标准（Evaluation Metrics）

-   **分类准确率（Classification Accuracy）：**
    论文的主要评价指标。作者绘制准确率随 SNR
    变化的曲线，并比较四种图像表示方式的分类效果。
-   **混淆矩阵（Confusion Matrix）：**
    用于展示不同调制类别之间的误分类情况。
-   **单次分类计算时间（Calculation Time per Classification）：**
    用于评价推理开销和实际应用可行性。
-   **训练时间（Training Time）：** 报告两种 CNN
    模型的训练时间，用于说明离线训练成本。
-   **未作为主要指标报告的内容：** 论文没有将
    BER、分组错误率、Precision、Recall 或 F1-score 作为主要评价指标。

### 主要实验结果

-   **图像表示方式的影响：** 在 SNR = 2 dB 的 8PSK
    实验中，使用普通二值星座图时准确率为 82.8%；使用灰度图时为
    88.8%；使用增强灰度图时为 96.5%；使用三通道图像时达到 97.1%。
-   **SNR = 4 dB 时的混淆矩阵：** 使用三通道图像和 GoogLeNet
    时，BPSK、4ASK、QPSK、OQPSK 和 8PSK 在报告的测试中均达到 100%
    准确率。高阶 QAM 类别更难识别：
    -   16QAM：准确率为 74.1%，最主要的混淆类别是 64QAM。
    -   32QAM：准确率为 93.8%。
    -   64QAM：准确率为 68.3%，最主要的混淆类别是 16QAM。
-   **准确率与 SNR 的关系：** 对比的五种方法中，分类准确率均随着 SNR
    提高而改善。两种 CNN
    方法表现最好，且准确率相近；在论文报告的对比中，SVM
    方法优于仅使用累积量的基线方法。
-   **推理时间：** 在作者的测试平台（Intel Xeon X5690 CPU 和 NVIDIA
    Tesla K40m GPU）上，AlexNet 每次分类约需 6.6 ms，GoogLeNet 约需 18
    ms。SVM-5 在 SNR 为 0、4、10 dB 时的报告时间分别为 3.2、1.2、0.1
    ms；SVM-7 分别为 4.2、2.5、1.2 ms。因此，在该实验设置下，CNN
    获得了更高准确率，但推理时间高于 SVM 基线方法。

## 5. 对咱们课题的启发（Key Takeaways）

-   **主要贡献：** 本文的核心贡献不只是使用 AlexNet 和
    GoogLeNet，而是建立了一套将复数 I/Q
    采样数据转换为星座灰度图或三通道图像的流程，使其能够作为 CNN
    的输入，并研究图像表示方式及其参数对分类性能的影响。
-   **图像表示方式很重要：**
    对于同一组接收采样数据，使用采样密度和距离加权强度，比简单地将被占用像素设为相同值的二值星座图保留了更多有用信息。在
    SNR = 2 dB 的 8PSK 实验中，三通道图像取得了最高准确率 97.1%。
-   **较难区分的类别：** 混淆矩阵显示，16QAM 和 64QAM
    容易发生混淆。这说明即使低阶调制类别能够被准确识别，高阶调制方式之间的区分仍然具有挑战性。
-   **准确率与复杂度之间的权衡：** 在论文报告的准确率对比中，CNN
    优于累积量和 SVM
    基线方法，但推理时间更长。作者认为，当调制方式不会频繁变化时，毫秒级的推理时间可能是可以接受的。
-   **对数据增强的启发：** 论文讨论了当生成图像大于 CNN
    所需输入尺寸时采用图像裁剪的方法。但作者发现，如果训练时采用随机裁剪，而测试时采用单次裁剪或十次裁剪，训练与测试的处理方式不一致可能降低准确率；对
    AlexNet 而言，使用 227 × 227
    图像且不裁剪的效果较好。论文没有系统研究在信号域加入相位偏移、频率偏移、衰落或其他信道损伤的数据增强方法。三通道图像应理解为三种不同的图像强度映射，而不是三组独立增强的信号观测。
-   **对迁移学习的启发：** 作者对已有的 AlexNet 和 GoogLeNet
    结构进行了适配，并将分类输出修改为八类。但是，论文没有清楚说明使用预训练权重进行微调的具体流程，也没有比较迁移学习与从头训练的效果。因此，本文能够说明已有
    CNN 架构可以适配 AMC 任务，但不能单独作为迁移学习对 AMC 有效的证据。
-   **研究范围与局限性：**
    信号模型假设接收端已经完成相干同步，以及载波、定时和波形恢复。论文没有系统评估广泛的衰落信道或干扰环境；作者在结论中将衰落信道和干扰列为未来研究方向。因此，不能将本文结果理解为模型在任意真实无线信道环境下都具有鲁棒性。
