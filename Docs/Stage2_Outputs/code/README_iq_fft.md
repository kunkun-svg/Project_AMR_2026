## 代码原理

1. **复数 IQ**：`load_iq()` 读取表头 `I,Q` 的两列有限数值，形成 `x = I + 1j * Q`。I 为同相分量、Q 为正交分量，分别作为实部和虚部；一个复数采样同时描述幅度与相位。
2. **负频率**：在 `x = I + jQ` 的约定下，`exp(+j*2*pi*f*t)` 随时间在复平面逆时针旋转，`exp(-j*2*pi*f*t)` 顺时针旋转。负频率表示相位变化方向，与负幅度无关。IQ 基带中的正负频率也可表示相对中心频率的上下偏移。实信号频谱具有共轭对称性，复数 IQ 一般不对称，因此必须保留双边谱；对 Q 改变符号会将频谱左右翻转。
3. **FFT 与幅度归一化**：`compute_fft()` 使用完整的 `np.fft.fft(x)`，再除以 `N`。整周期复指数 `A*exp(j*2*pi*f*t)` 的峰值为 `abs(A)`。这里是复数双边幅度谱，不乘 2；也不除以最大峰值，因此两个分量的绝对幅度与幅度比都得到保留。
4. **fftshift**：`fftfreq(N, d=1/fs)` 提供真实频率坐标。原始 FFT 按零频、正频、负频排列；频率轴与频谱同时 `fftshift`，使负频率在左、零频在中、正频率在右。只移动其中一个会导致频率与幅度错配。此样本有 4096 点，移位后频率为 −2048 至 +2047 Hz。
5. **避免 log10(0)**：先取 `amplitude = abs(spectrum)`，再计算 `20*log10(max(amplitude, 1e-12))`。这是幅度的 dB 表示，参考幅度为 1，下限为 −240 dB。下限只用于对数显示，峰值排序仍使用原始线性幅度；这里没有把结果标为功率谱密度或 dBm。
6. **绘图与峰值**：上图放大前 96 个采样点的 I、Q 波形，下图使用全部 4096 点计算双边 FFT，并标注实际测得的两个最高频点。频点从计算结果中排序选出，+300、−700 仅用于事后核对。

本样本的两个分量均落在整数频点上，因此不加窗也能直接核对幅度，等价于使用矩形窗。若更换为非整周期信号，会出现频谱泄漏，两个最大频点可能同属一个主瓣；这种情况下需要加窗、补偿窗的相干增益，并采用局部峰检测或插值，不能直接把两个最大频点解释为两个独立分量。`--check-sample` 只适用于这份配套样本。

## FFT 与 STFT 的区别

FFT 是快速计算离散傅里叶变换（DFT）的算法。本脚本对整段记录做一次 FFT，回答“整段记录中有哪些频率、各有多强”，不直接标明它们出现的时间。

STFT（短时傅里叶变换）将信号切成滑动短窗，对每一窗加窗并计算 FFT，得到随时间变化的频谱矩阵；通常将其幅度或功率画为时频图。短窗有利于定位快速变化，长窗有利于分辨相近频率，二者需要权衡。零填充可以加密频率采样网格，但不会提高由窗长度决定的实际频率分辨能力。对复数 IQ 做 STFT 时同样应保留正负频率，只沿频率维移动频谱。
